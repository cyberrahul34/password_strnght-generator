# 🔐 Password Strength Checker & Generator

A Python-based Cyber Security project that checks password strength
and generates random passwords to help users understand basic
password security.

## 📌 About the Project

The Password Strength Checker & Generator is a command-line
application developed using Python. It evaluates passwords based
on their length and character variety and classifies them as
WEAK, MEDIUM, or STRONG.

The application can also generate random passwords using Python's
`secrets` module.

## ✨ Features

- 🔍 Checks password strength.
- 📊 Displays a password complexity score out of 5.
- 🔐 Classifies passwords as WEAK, MEDIUM, or STRONG.
- 🎲 Generates random passwords.
- 🔠 Uses lowercase letters, uppercase letters, digits, and symbols.
- 📋 Supports optional clipboard copying.
- 💻 Simple and beginner-friendly command-line interface.

## 🛠️ Technologies Used

- Python 3
- `string` module
- `secrets` module
- `tkinter` for optional clipboard functionality

## ⚙️ Requirements

- Python 3 installed on your computer.
- Visual Studio Code or another Python editor (optional).
